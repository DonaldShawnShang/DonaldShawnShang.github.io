# donaldshawnshang.github.io

Personal academic homepage of **Wentao Shang (尚文韬)** — live at <https://donaldshawnshang.github.io/>.

Plain static HTML/CSS (no build step, no external CDNs).

```
index.html                 page content
assets/css/style.css       styles (colour/typography tokens at the top)
assets/img/                avatar, favicon, paper overview figures
assets/cv/                 public CV (PDF)
assets/fonts/              self-hosted Source Serif 4 + JetBrains Mono (SIL OFL)
```

Icons: Font Awesome Free 6.6.0 (CC BY 4.0), inlined as an SVG sprite in `index.html`.

To update: edit `index.html`, preview with `python3 -m http.server`, then commit and push to `main`.
